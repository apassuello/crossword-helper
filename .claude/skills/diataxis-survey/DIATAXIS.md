# Diátaxis Classification Rules

Every document belongs to exactly one type.

|                   | Learning    | Working      |
| ----------------- | ----------- | ------------ |
| **Doing**         | Tutorial    | How-to guide |
| **Understanding** | Explanation | Reference    |

## Tutorials

Tutorials are lessons.

The reader is learning.

Tutorials:

- teach through doing
- guide step-by-step
- make all decisions for the reader
- produce visible outcomes at every step

Tutorials are NOT:

- explanations
- references
- architecture discussions
- collections of options

## How-to Guides

How-to guides help competent users complete specific tasks.

How-to guides:

- are goal-oriented
- assume user competence
- omit teaching and motivation
- focus only on completing the task

How-to guides are NOT:

- onboarding lessons
- conceptual overviews
- API descriptions

## Reference

Reference describes the machinery.

Reference:

- mirrors the structure of the system itself
- describes facts only
- is exhaustive and precise
- contains no instruction or explanation

Reference is NOT:

- tutorials
- design rationale
- workflow guidance

## Explanation

Explanation helps readers understand.

Explanation:

- describes architecture and trade-offs
- explains why decisions were made
- provides conceptual models
- connects ideas together

Explanation is NOT:

- task-oriented
- step-by-step
- exhaustive API documentation
